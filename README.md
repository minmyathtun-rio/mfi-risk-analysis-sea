# 📊 Microfinance Liquidity & Credit Risk Analysis (SEA Region)

## 📌 Executive Summary
This project analyzes liquidity and financial risk metrics across Microfinance Institutions (MFIs) in Southeast Asia. Using loan-level data, I evaluated Funding Gaps, Receivable Completion Rates, and Sector Risk Profiles to provide actionable risk-mitigation strategies.

## 🛠️ Tech Stack & Tools
* **Database:** PostgreSQL (Data Storage & Analytics)
* **SQL Client:** DataGrip
* **Visualization:** Tableau Public
* **Data Source:** Kiva Microfinance Dataset (Kaggle)

## 💡 Key Analytical Findings
1. **Funding Shortfall:** Identified key funding gaps in specific sectors (e.g., Agriculture) in the SEA region.
2. **Repayment Risk:** Analyzed loan terms vs. repayment completion rates to spot potential default risks.
